# K-001: Fix broken `Blended_Profit_Per_Unit` column reference

**Priority:** P0-Critical  
**Sprint:** 1  
**Estimate:** 1 hour  
**Type:** Bug  
**Filed by:** Code audit  
**Component:** `data_processor.py`

---

## Description

On line 268 of `data_processor.py`, the `Cashflow_Healthy` column is computed by referencing `Blended_Profit_Per_Unit`, but no column with that name exists. Only `Blended_Profit_Per_Sale` is created (line 263–265). This will raise a `KeyError` at runtime when `calculate_sku_metrics()` is called.

## Current Behaviour

```python
# Line 267-268
sku_stats['Cashflow_Healthy'] = sku_stats['Blended_Profit_Per_Unit'] >= sku_stats['Unit_COGS']
# KeyError: 'Blended_Profit_Per_Unit'
```

## Expected Behaviour

The comparison should use the column that actually exists:

```python
sku_stats['Cashflow_Healthy'] = sku_stats['Blended_Profit_Per_Sale'] >= sku_stats['Unit_COGS']
```

## Files to Modify

| File | Line |
|------|------|
| `data_processor.py` | 268 |

## Steps to Implement

1. Open `data_processor.py`
2. Change line 268 from:
   ```python
   sku_stats['Cashflow_Healthy'] = sku_stats['Blended_Profit_Per_Unit'] >= sku_stats['Unit_COGS']
   ```
   to:
   ```python
   sku_stats['Cashflow_Healthy'] = sku_stats['Blended_Profit_Per_Sale'] >= sku_stats['Unit_COGS']
   ```
