# K-004: Wire `audit_report.html` to a route

**Priority:** P3-NiceToHave  
**Sprint:** 1  
**Estimate:** 2 hours  
**Type:** Feature  
**Filed by:** Code audit  
**Components:** `main.py`, `templates/audit_report.html`

## Description

A fully styled 274-line `audit_report.html` template exists in the `templates/` directory but is not wired to any route in `main.py`. It appears to be a standalone audit/health report with dark theme, glassmorphism cards, metric tiles, violation flags, and print support. This is ready-to-ship UI that nobody can access.

## Current Behaviour

`templates/audit_report.html` exists but is unreachable — no route renders it.

## Expected Behaviour

The report should be available at a URL (e.g., `/audit-report`) and populated with live data from the auditor and data processor.

## Files to Modify

| File | Lines | Action |
|------|-------|--------|
| `main.py` | After line 269 | Add new route |
| `templates/audit_report.html` | Review | Ensure template variables match |

## Steps to Implement

1. Review `audit_report.html` — read the template variable names it expects.
2. Add a new route in `main.py`:
   ```python
   @app.get("/audit-report", response_class=HTMLResponse)
   async def audit_report(request: Request, start_date: str = None, end_date: str = None, db: Session = Depends(get_db)):
       start_date, end_date, parsed_start, parsed_end = _parse_dates(start_date, end_date)
       summary = dp.calculate_monthly_summary(db, parsed_start, parsed_end)
       # Build the metrics dict expected by the template
       metrics = {
           "unit_session_pct": summary.get("Unit_Session_Pct", 0),
           "tacos_pct": summary.get("TACOS", 0),
           "return_pct": summary.get("Return_Pct", 0),
           "profit_per_unit": summary.get("Profit_Per_Unit", 0),
           "net_margin_pct": summary.get("Net_Margin_Pct", 0),
           "net_income": summary.get("Net_Income", 0),
       }
       audit_result = auditor.audit_health(metrics)
       return templates.TemplateResponse("audit_report.html", {
           "request": request,
           "audit": audit_result,
           "metrics": metrics,
           "start_date": start_date,
           "end_date": end_date,
       })
   ```
3. Add a navigation link to the report in the base template (or verify the existing template has its own nav).
4. Test the route renders correctly with live data.
