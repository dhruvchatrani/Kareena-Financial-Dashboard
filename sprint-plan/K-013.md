## Description

The `/upload-manual` endpoint accepts arbitrary files with no validation:
- No content-type check (PDF named `.csv` would be processed and fail cryptically)
- No file size limit (a 2GB file would crash the server)
- No schema pre-validation (a CSV with wrong columns is processed until `clean_numeric` returns all zeros)
- Temp files are saved to disk before any validation

## Current Behaviour

```python
async def save_file(uf: UploadFile) -> str:
    path = os.path.join(upload_dir, uf.filename)
    with open(path, "wb") as f:
        f.write(await uf.read())
    return path
# Then: processor.sync_settlement_csv(path, ...) — might fail 50% through
```

## Expected Behaviour

- File size limit: reject files > 50MB before reading
- Content-type verification: match expected MIME types per field
- Schema pre-validation: check required columns exist before inserting any data
- File extension whitelist per field

## Steps to Implement

1. Add constants at the top of `main.py`:
   ```python
   MAX_UPLOAD_SIZE = 50 * 1024 * 1024  # 50MB
   ALLOWED_EXTENSIONS = {
       'settlement': {'.csv'},
       'deferred': {'.csv'},
       'business': {'.csv'},
       'ads': {'.xlsx', '.csv'},
       'returns': {'.xml'},
   }
   ```

2. Create a validation function:
   ```python
   def validate_upload(file: UploadFile, field_name: str):
       # Check extension
       ext = os.path.splitext(file.filename)[1].lower()
       if ext not in ALLOWED_EXTENSIONS.get(field_name, set()):
           raise ValueError(f"Invalid file type '{ext}' for {field_name}. Allowed: {ALLOWED_EXTENSIONS[field_name]}")
       
       # Check size (read first bytes, check Content-Length)
       file.file.seek(0, os.SEEK_END)
       size = file.file.tell()
       file.file.seek(0)
       if size > MAX_UPLOAD_SIZE:
           raise ValueError(f"File too large: {size / 1024 / 1024:.1f}MB (max {MAX_UPLOAD_SIZE / 1024 / 1024:.0f}MB)")
   ```

3. Add schema pre-validation in `processor.py`:
   ```python
   REQUIRED_COLUMNS = {
       'settlement_detailed': ['sku', 'type', 'product sales', 'total'],
       'settlement_transaction': ['date', 'transaction type', 'total (inr)'],
       'business': ['SKU', 'Sessions - Total', 'Units Ordered'],
   }
   
   def validate_schema(df, format_name):
       missing = [c for c in REQUIRED_COLUMNS[format_name] if c not in df.columns]
       if missing:
           raise ValueError(f"Missing required columns for {format_name}: {missing}")
   ```

4. Apply validation before any DB operations in the upload route.

5. Clean up temp files even on validation failure.

## Acceptance Criteria

- [ ] Invalid file extensions are rejected with a clear error message
- [ ] Files > 50MB are rejected before any processing
- [ ] CSV files with wrong columns fail with a specific message listing the missing columns
- [ ] Valid files process normally
- [ ] Temp files are cleaned up even when validation fails
