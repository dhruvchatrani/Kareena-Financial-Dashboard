# K-014: Improve `clean_numeric` error reporting

**Priority:** P2-Important  
**Sprint:** 3  
**Estimate:** 2 hours  
**Type:** Reliability  
**Filed by:** Code audit  
**Components:** `utils.py` (after K-003), `processor.py`

---

## Description

The `clean_numeric()` function silently returns `0.0` for any value it cannot parse. This means if Amazon changes a column format (e.g., starts using a different currency symbol or locale format), the data silently zeroes out without any warning. The business user sees ₹0 in revenue for the month and has no indication that the data was not parsed correctly.

## Current Behaviour

```python
def clean_numeric(val):
    try:
        return float(val_str)
    except ValueError:
        return 0.0  # Silent data loss
```

## Expected Behaviour

- Log a warning on first failure per file/batch so developers can detect format changes
- Track the count of unparseable values and surface it in the upload result summary
- Optionally accept a `context` parameter (e.g., column name) for better error messages

## Steps to Implement

1. Update `clean_numeric()` in `utils.py`:
   ```python
   import logging
   
   _logger = logging.getLogger(__name__)
   
   def clean_numeric(val, context=None):
       if pd.isna(val) or val == '':
           return 0.0
       val_str = str(val).replace('₹', '').replace(',', '').strip()
       if val_str.startswith('(') and val_str.endswith(')'):
           val_str = '-' + val_str[1:-1]
       try:
           return float(val_str)
       except ValueError:
           ctx = f" [{context}]" if context else ""
           _logger.warning(f"clean_numeric: could not parse '{val}'{ctx} — returning 0.0")
           return 0.0
   ```

2. Update callers to pass context:
   ```python
   clean_numeric(row.get('product sales', 0.0), context=f"Order {order_id}, SKU {sku}")
   ```

3. In `processor.py`, aggregate warning counts and include them in the upload summary:
   ```python
   # Use a Counter to track unparseable columns
   from collections import Counter
   parse_errors = Counter()
   ```

## Acceptance Criteria

- [ ] Unparseable values are logged at `WARNING` level with column/row context
- [ ] Upload summary includes a count of parsing warnings if any occurred
- [ ] Existing parsing of valid values is unaffected
- [ ] No new dependencies required
