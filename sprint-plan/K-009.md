# K-009: Add consistent error handling and logging middleware

**Priority:** P2-Important  
**Sprint:** 2  
**Estimate:** 6 hours  
**Type:** Improvement  
**Filed by:** Code audit  
**Components:** `main.py`, all routes

---

## Description

Error handling is inconsistent across routes:
- Some return `HTMLResponse` with inline error messages (`main.py:345`, `main.py:517`)
- Some raise HTTP exceptions implicitly
- Some swallow exceptions silently (e.g., `processor.py` with `logging.warning` then returning 0)
- No global exception handler

This makes debugging production issues difficult and creates a poor user experience when things go wrong.

## Current Behaviour

Each route handles errors differently — some with inline HTML, some with plain text, some silently.

## Expected Behaviour

- A global exception handler that returns a consistent error page
- Structured logging with request IDs
- All processor functions should raise (not silently return 0) so callers can handle errors upstream
- Upload failures should show the user which file failed and why

## Steps to Implement

1. Add a global exception handler in `main.py`:
   ```python
   @app.exception_handler(Exception)
   async def global_exception_handler(request: Request, exc: Exception):
       logging.error(f"Unhandled exception on {request.url}: {exc}", exc_info=True)
       return templates.TemplateResponse("error.html", {
           "request": request,
           "error": str(exc),
       }, status_code=500)
   ```

2. Create `templates/error.html` with a styled error page showing the message and a "Go back" link.

3. Update `processor.py` functions to raise exceptions instead of returning 0 on failure:
   ```python
   def sync_settlement_csv(...):
       if fmt == 'unknown':
           raise ValueError(f"Unknown CSV format for {file_path}")
       # ... instead of logging and returning 0
   ```

4. Update `main.py` upload handler to catch per-file errors and report them individually.

5. Add structured logging (JSON format with request ID):
   ```python
   import uuid
   @app.middleware("http")
   async def add_request_id(request: Request, call_next):
       request_id = str(uuid.uuid4())[:8]
       with contextlib.suppress(AttributeError):
           request.state.request_id = request_id
       logging.info(f"[{request_id}] {request.method} {request.url}")
       response = await call_next(request)
       response.headers["X-Request-ID"] = request_id
       return response
   ```
