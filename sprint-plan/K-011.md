# K-011: Add basic authentication layer

**Priority:** P1-MustHave  
**Sprint:** 3  
**Estimate:** 10 hours  
**Type:** Security  
**Filed by:** Code audit  
**Components:** `main.py`, templates

---

## Description

The dashboard has zero authentication. Anyone who can reach `http://127.0.0.1:8000` (or the host's IP if bound to `0.0.0.0`) can:
- View all financial data (sales, profit, SKU details)
- Download the full SQLite database (`/admin/backup`)
- Delete all data (`/admin/reset-db`)
- Modify settings and inventory

Since this is a local-first application, the auth should be simple but effective.

## Current Behaviour

No authentication at all. All routes are public.

## Expected Behaviour

Option A (Recommended — Simple): HTTP Basic Auth with a single configurable username/password stored in `.env`:

```
DASHBOARD_USERNAME=admin
DASHBOARD_PASSWORD=changeme
```

Option B (Alternative): Session-based auth with a login page, using `itsdangerous` signed cookies.

**For this ticket, implement Option A.**

## Steps to Implement

1. Add `.env` vars:
   ```
   DASHBOARD_USERNAME=admin
   DASHBOARD_PASSWORD=<generate-a-password>
   ```

2. Create an auth dependency in a new `auth.py`:
   ```python
   import os
   import secrets
   from fastapi import Depends, HTTPException, status
   from fastapi.security import HTTPBasic, HTTPBasicCredentials
   
   security = HTTPBasic()
   
   def verify_credentials(credentials: HTTPBasicCredentials = Depends(security)):
       correct_username = os.getenv("DASHBOARD_USERNAME", "admin")
       correct_password = os.getenv("DASHBOARD_PASSWORD", "")
       # Constant-time comparison
       username_match = secrets.compare_digest(credentials.username, correct_username)
       password_match = secrets.compare_digest(credentials.password, correct_password)
       if not (username_match and password_match):
           raise HTTPException(
               status_code=status.HTTP_401_UNAUTHORIZED,
               detail="Incorrect username or password",
               headers={"WWW-Authenticate": "Basic"},
           )
       return credentials.username
   ```

3. Apply the dependency to all routes:
   ```python
   @app.get("/", response_class=HTMLResponse)
   async def index(request: Request, ..., _=Depends(verify_credentials), db: Session = Depends(get_db)):
   ```

4. Ensure static files and the login prompt itself don't loop (FastAPI's `HTTPBasic` handles the browser login dialog).

5. Update `.env.example` with the new vars.

6. Add a note in `README.md` about setting the initial password.

## Acceptance Criteria

- [ ] Visiting any page without auth shows the browser login dialog
- [ ] Wrong credentials return 401
- [ ] Correct credentials grant access to all routes
- [ ] `/admin/reset-db`, `/admin/backup` are also protected
- [ ] .env.example includes `DASHBOARD_USERNAME` and `DASHBOARD_PASSWORD`
- [ ] Auth is applied as a dependency, not middleware (testable)
