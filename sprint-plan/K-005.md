# K-005: Fix `FORMULA_DOCUMENTATION.md` silent placeholder

**Priority:** P3-NiceToHave  
**Sprint:** 1  
**Estimate:** 1 hour  
**Type:** Bug  
**Filed by:** Code audit  
**Components:** `main.py`

---

## Description

The `/docs` route (line 257–273) silently creates a placeholder `FORMULA_DOCUMENTATION.md` file if it doesn't exist:

```python
if not os.path.exists(sop_file):
    with open(sop_file, "w") as f:
        f.write("# Standard Operating Procedure\nEdit this content from the UI.")
```

This is confusing — if the file was accidentally deleted or never committed, the user sees a generic stub instead of knowing something is wrong. The file is referenced in `README.md` as containing all financial formulas, so its absence is meaningful.

## Current Behaviour

Missing file → auto-created placeholder → user sees "Edit this content from the UI."

## Expected Behaviour

Two possible approaches (choose one):

**Option A (Recommended):** Return a clear 404 template explaining the file is missing and link to create it. Remove the auto-creation logic.

**Option B:** If the file should genuinely be editable from the UI, persist changes back to the file when saved, and do not overwrite existing content. Add a save endpoint.

## Files to Modify

| File | Lines |
|------|-------|
| `main.py` | 259–266 |

## Steps to Implement (Option A)

1. Remove the `if not os.path.exists()` block (lines 260–263).
2. Change the route to handle `FileNotFoundError` gracefully:
   ```python
   @app.get("/docs", response_class=HTMLResponse)
   async def docs_page(request: Request):
       sop_file = "FORMULA_DOCUMENTATION.md"
       try:
           with open(sop_file, "r") as f:
               content_md = f.read()
       except FileNotFoundError:
           return templates.TemplateResponse("docs.html", {
               "request": request,
               "content_html": "<div class='p-8 text-center'><h2>Documentation Not Found</h2><p>The file FORMULA_DOCUMENTATION.md is missing. Commit it to the repository or create it manually.</p></div>",
               "content_md": "",
           })
   ```
