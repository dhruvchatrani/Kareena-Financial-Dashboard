# K-018: Make WhatsApp import directory configurable

**Priority:** P3-NiceToHave  
**Sprint:** 4  
**Estimate:** 2 hours  
**Type:** UX  
**Filed by:** Code audit  
**Components:** `main.py`, `templates/admin.html`, `.env`

---

## Description

The `/admin/import-whatsapp` route uses a hardcoded directory name:

```python
whatsapp_dir = "WhatsApp Chat with Fin dashboard brief"
if not os.path.exists(whatsapp_dir):
    return HTMLResponse(content="WhatsApp folder not found", status_code=404)
```

This makes the feature brittle — if the directory name changes or is moved, the feature silently breaks. It also assumes a specific naming convention that may not match the user's actual folder name.

## Current Behaviour

Directory name is hardcoded in `main.py:349`. No way to configure it.

## Expected Behaviour

The directory path should be configurable via:
1. An environment variable `WHATSAPP_IMPORT_DIR` (primary)
2. Fallback to the current hardcoded value

## Steps to Implement

1. Add to `.env` and `.env.example`:
   ```
   WHATSAPP_IMPORT_DIR=WhatsApp Chat with Fin dashboard brief
   ```

2. Update `main.py`:
   ```python
   import os
   
   @app.post("/admin/import-whatsapp")
   async def import_whatsapp(db: Session = Depends(get_db)):
       whatsapp_dir = os.getenv("WHATSAPP_IMPORT_DIR", "WhatsApp Chat with Fin dashboard brief")
       # ... rest of function
   ```

3. Update `templates/admin.html` to show the current configured path so the user knows where to place files.

## Acceptance Criteria

- [ ] Setting `WHATSAPP_IMPORT_DIR` in `.env` changes the directory scanned
- [ ] When the env var is not set, it falls back to the original hardcoded path
- [ ] Admin page displays the current configured path
- [ ] `ruff check .` passes
