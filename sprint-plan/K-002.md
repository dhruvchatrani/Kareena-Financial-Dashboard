# K-002: Remove unused imports across codebase

**Priority:** P3-Cleanup  
**Sprint:** 1

**Components:** `main.py`, `data_processor.py`

## Description

Several modules import Python packages that are never used. These create noise, slow import times slightly, and can cause confusion for new developers.

## Current Behaviour

Unused imports:

| File | Import |
|------|--------|
| `main.py:14` | `import shutil` |
| `data_processor.py:7` | `from sqlalchemy import func` |
| `data_processor.py:5` | `Any`, `Optional` from typing |
| `main.py:20` | `Optional` from typing |

## Expected Behaviour

No unused imports in any source file.

## Files to Modify

| File | Lines |
|------|-------|
| `main.py` | 14, 20 |
| `data_processor.py` | 5, 7 |

## Steps to Implement

1. In `main.py`, remove `import shutil` (line 14) and `from typing import Optional` (line 20) — `Optional` is not used anywhere in the file.
2. In `data_processor.py`, change line 5 from `from typing import Dict, Any, Optional, List` to `from typing import Dict, List`. Remove `from sqlalchemy import func` (line 7).
3. Run `ruff check .` to confirm no lint errors.
4. Run the application and verify routes still work.

## Acceptance Criteria

- [ ] `ruff check .` passes with no errors
- [ ] Application starts without `ImportError`
