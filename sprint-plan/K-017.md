# K-017: Add loading/processing state to upload flow

**Priority:** P3-NiceToHave  
**Sprint:** 4  
**Estimate:** 4 hours  
**Type:** UX  
**Filed by:** Code audit  
**Components:** `templates/audit.html`, `main.py`

---

## Description

The multi-file upload at `/upload-manual` can take 10–60 seconds depending on file sizes. During this time, the browser shows no indication that anything is happening. Users may:
- Click the upload button multiple times (causing duplicate uploads)
- Navigate away, assuming the page is broken
- Close the browser

The response is synchronous — the browser waits for the full response before showing anything.

## Current Behaviour

No loading indicator. The form submits and the page appears to hang until the redirect response arrives.

## Expected Behaviour

- Show a loading overlay with a spinner and "Processing..." message on form submit
- Disable the submit button to prevent double-clicks
- Optionally show a progress message per file (e.g., "Processing Settlement CSV...", "Processing Ads Report...")

## Steps to Implement

1. Update `templates/audit.html`:
   ```html
   <form id="upload-form" action="/upload-manual" method="post" enctype="multipart/form-data">
       <!-- existing fields -->
       <button type="submit" id="submit-btn" class="...">Upload & Sync</button>
       <div id="loading-overlay" class="hidden fixed inset-0 bg-gray-900 bg-opacity-50 flex items-center justify-center">
           <div class="bg-white p-8 rounded-lg shadow-xl text-center">
               <div class="animate-spin h-10 w-10 border-4 border-blue-500 border-t-transparent rounded-full mx-auto mb-4"></div>
               <p id="loading-text" class="text-lg font-semibold">Processing your files...</p>
               <p class="text-sm text-gray-500">This may take up to a minute. Please don't close this page.</p>
           </div>
       </div>
   </form>
   
   <script>
   document.getElementById('upload-form').addEventListener('submit', function() {
       document.getElementById('loading-overlay').classList.remove('hidden');
       document.getElementById('submit-btn').disabled = true;
   });
   </script>
   ```

2. No backend changes needed — this is purely a frontend improvement.

3. Test with a large file to confirm the spinner appears.

## Acceptance Criteria

- [ ] Clicking "Upload & Sync" shows a loading overlay immediately
- [ ] The submit button is disabled while processing
- [ ] The overlay disappears when the redirect response arrives (browser navigates)
- [ ] Works in Chrome, Firefox, and Edge
